# design.md — 書店POPのデザインルール

day3(本屋のピックアップコーナー)の看板・POPを整えるための基準。
参考画像と目視の所見は `pop_refs/README.md`。

## 進め方
1. 参考を3〜5枚集め、「なぜ良いか」を一言メモする(`pop_refs/`)。
2. Canva等のテンプレは丸ごと使わず、レイアウトの骨格だけ借りる。
3. 文言・色・写真を自分の本に合わせて差し替える。

## 基本ルール
| 項目 | ルール |
|---|---|
| 色 | 3色まで(ベース・メイン・アクセント)。本の表紙から色を拾う |
| 書体 | 2種類まで。見出し用1つ、本文用1つ |
| 情報量 | 一番伝えたい一言だけ大きく。残りは削る |
| 余白 | 端から余白を取る。文字を板の縁やほかの物に接触させない |
| 大小差 | 見出しは本文の3倍以上 |
| 装飾 | 枠線・影・飾りは少なく。背景は1色が基本 |
| 主役 | 看板の主役は本そのもの。POPは表紙のトーンに寄せる |
| 手書き風 | 見出しだけ。本文は整った書体 |
| 視線 | 吹き出し・矢印などで入口と出口を決める |
| 情報(価格・著者) | 最下部に小さくまとめる |

## 「おしゃれに見えない」原因と直し方
| 原因 | 直し方 |
|---|---|
| 色が多い | 3色に絞る |
| 書体が多い | 2種類に絞る |
| 情報の詰めすぎ | 一言だけ残す |
| 余白不足 | 端から余白を取る |
| 大小差が弱い | 見出しを3倍以上にする |
| 装飾過多 | 半分に減らす |
| 背景が看板に勝っている | 背景の彩度を落とし、看板を浮かせる |

## bookstore.html への適用メモ(2026-11-05 時点の所見)
- 大看板「PICK UP おすすめの本」: 文字が板の左右でクリップされ、棚の柱とも重なる。「PICK UP」と「おすすめの本」が同サイズで主従がない。板がPOPより大きすぎる。
- 中央POP: 茶色い台紙に茶色い文字でコントラストが低い。見出しがなく全文が同サイズ。
- 黄色いギザギザPOP: 目立つが文字が小さく、右端で切れている。
- 背景の本棚: 高彩度の背表紙が多数並び、看板より目立つ。

### 直す優先順位
1. 背景の本棚の彩度を落とす。
2. 大看板の文字を板の内側に収めて余白を取り、「おすすめの本」を大きく、「PICK UP」を小さくする。
3. 中央POPは一言だけ大きくして、残りは小さくまとめる。台紙と文字の明暗差をつける。

## 運用
- 文言・見出しの内容はユーザーが決める。Claudeは決められた内容を実装するだけ(`../CLAUDE.md` のルール)。
