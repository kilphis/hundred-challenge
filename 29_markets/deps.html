1. モジュール依存

矢印 A → B は「B が A を use する」(CLAUDE.md の「defs → state → logic → input / render」と同じ向き)。実際の use crate::… 文から作成。main.rs の定数(CELL, ROWS…)は defs 以外の全員が使うので線は省略。

注意: input と render は互いに use している(input → render の cursor_world、render → input の menu_rect/tab_rect/hit)。input・render・logic は defs を直接 use せず、m.def 経由で読む。

main.rsstate → World / logic → step_market / input → input / render → setup, render / save → load / sim → run

2. 1フレームの流れ

オレンジの線 = Bevy の実行順。main.rs: .add_systems(Update, (tick, input::input, render::render).chain()) なので tick → input → render の順(tick が先)。灰色の線 = 呼ぶ → 呼ばれる。点線の箱 = 別の所にも出てくる同じ関数。
