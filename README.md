# 100日チャレンジ

毎日ひとつ作る。`dayN/` または `N/` に各日の成果物。

| Day | 内容 | 実行 |
|---|---|---|
| 1 | 縦スクロール弾幕シューティング(ターミナル) | `uv run day1/shooting.py` |
| 2 | ガチャ(ターミナル ANSI エフェクト) | `uv run day2/gacha.py` |
| 3 | 本屋のピックアップコーナー(Three.js) | [`day3/bookstore.html`](https://kilphis.github.io/hundred-challenge/day3/bookstore.html)  |
| 4 | 箱庭ゲーム(pygame-ce) | `uv run day4/hakoniwa.py` |
| 5 | 自作イラストのゲーム | [`day5/game.html`](https://kilphis.github.io/hundred-challenge/day5/game.html) |
| 6 | 画像 → グリッド | [`day6/index.html`](https://kilphis.github.io/hundred-challenge/day6/index.html) |
| 7 | 跳ね返るボールの最小ゲームループ(C#) | `dotnet run day7/ballgame.cs` |
| 8 | asset-stack | `8/README.md` 参照 |
| 9 | 自動運転ドライブ | [`9/drive.html`](https://kilphis.github.io/hundred-challenge/9/drive.html) |
| 10 | 的当て / 的当て 3D | [`10/archery.html`](https://kilphis.github.io/hundred-challenge/10/archery.html), [`10/archery3d.html`](https://kilphis.github.io/hundred-challenge/10/archery3d.html) |
| 11 | 馬車とゴースト | [`11/cart_archer.html`](https://kilphis.github.io/hundred-challenge/11/cart_archer.html) |
| 12 | 成果物ギャラリー | [`12/gallery.html`](https://kilphis.github.io/hundred-challenge/12/gallery.html) |
| 13 | Rust | `cd 13 && cargo run` |
| 14 | farm(Rust) | `cd 14 && cargo run` |
| 15 | 騎馬戦(Rust + macroquad, WASM) | `cd 15 && ./build_web.sh` → [`15/web/`](https://kilphis.github.io/hundred-challenge/15/web/) を配信 |

ブラウザで動く日は表のリンクから遊べる(GitHub Pages)。

フォント `14/assets/font.ttf`・`15/web/font.ttf` は PlemolJP(SIL Open Font License 1.1)。
