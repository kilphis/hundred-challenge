# day41 歩く灯籠 — 多脚の彫刻を IK で歩かせ、脚の付け根の曲げを見る

`index.html` をブラウザで開く(file:// のままで動く)。

| キー | 動き |
|---|---|
| M | 脚を曲げモーメントの大きさで塗る(暗い灰 = 0 → 橙 = 大) |
| I | IK の三角形(付け根・膝・足先)と、次の着地点の輪を見せる |
| V | 脚の種類を切り替える(撚り / 浮き出た脈 / 筋の束) |
| ↑ ↓ | 速さ |
| Space | 止める |

## ファイル

- `curve.js` … 脚のしなり。骨の両端(関節)は動かさず、途中だけ弓なりに曲げる(強さは `defs.js` の `curve`)
- `gait.js` … 歩き方と IK
- `bend.js` … 反力の分け方と曲げモーメント、脚の色

## 歩き方(gait.js)
脚ごとに「位相」を持たせ、1周期のうち `beta`(0.56)の間は接地、残りは遊脚。
6本は1つおきに2組に分け、半周期ずらす(3本ずつ交互)。いつも3本以上が地面にある。

- 接地中: 足先は地面の1点に固定。胴体が進むので、胴体から見ると足先は後ろへ流れる。
- 遊脚中: 足先を持ち上げ、**次の接地のちょうど真ん中で基準の立ち位置に来る点**へ弧で運ぶ。
  胴体がどこまで進むかは道すじの式から先に分かるので、着地点を先回りして決められる。

## IK(足先の位置 → 関節の角度)
脚は「付け根で水平に向きを変える」+「縦の面の中の2本の骨」。

1. 付け根を足先の方向へ水平に回す: `yaw = atan2(x, z)`
2. 縦の面の中で、付け根から足先までの距離を `r`、骨の長さを `L1`, `L2` とすると、
   三角形の3辺がそろうので余弦定理で内角が決まる。
   - 付け根の角 `α = acos((L1² + r² − L2²) / (2·L1·r))`
   - 膝の内角 `β = acos((L1² + L2² − r²) / (2·L1·L2))`
3. 上の骨 = 足先への角 `φ` から `α` だけ上へ(膝を上に出す解)、膝 = `π − β` だけ下へ折る。

`I` キーの白い三角形が、この三角形そのもの。

## 曲げ(bend.js)
1. **重さを接地中の脚に分ける**。脚が4本以上だと釣り合いの式だけでは決まらない(不静定)ので、
   「合力 = 重さ」「重心まわりのモーメント = 0」を満たす中で、反力の2乗和が最小になる分け方を選ぶ。
   接地の始まりと終わりは重みを0から上げ下げして、荷重がなめらかに移るようにしている。
2. **脚の中の曲げ**。足先に鉛直の反力 `R` だけが掛かるとすると、骨の上の点の曲げは
   `M = R × (その点と足先の水平距離)`。足先で0、水平に最も遠い付け根で最大になる。
   だから脚は付け根を太く、足先を細くしてある。
3. **付け根の応力** `σ = M / Z`、丸棒の断面係数 `Z = π r³ / 4`。半径が2倍になると応力は1/8。
   細い脚(r=16cm)だと同じ曲げで約 15 倍の応力になる。

4. **しなった骨**では、中心線が足先との直線からずれるぶん曲げが変わる。計算は曲がった中心線の点で行う(上に反った上の骨は付け根付近の水平距離が少し増える)。

近似: 足先の横向きの力、脚の自重、動きによる慣性は入れていない。重さ 18 t は鋳鉄の灯籠としての仮の値。
