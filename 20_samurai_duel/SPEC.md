# day20 侍との立ち合い(3D格闘)

`index.html` をブラウザで開く(Three.js r128、file:// で動く)。侍モデルは day19 の `models/samurai.js` のコピー。

## 決まっていること(ユーザー)
- CPU の侍と戦う3D格闘ゲーム。
- できることは 移動・ダッシュ・上段斬り だけ。
- リングは円形。
- 構え中にダッシュを押すと、その方向にステップして避ける(2026-11-13 追加)。

## Claude が仮に決めたこと(差し替え可)
- 操作: WASD/矢印=移動(カメラ基準)、Shift 押しっぱなし=ダッシュ、J/Space/クリック=上段斬り、R=やり直し。
- 向き: 歩き・待機・斬りは常に相手の方を向く。ダッシュ中だけ走る方向を向く。斬り中は動けない。
- 速さ: 歩き 120cm/秒(モーションは 55cm/秒基準なので再生を速める)、ダッシュ 320cm/秒。
- 勝敗: 一太刀当たれば決着(体力なし)。同じフレームで互いに当たれば「相打ち」。斬られた側は後ろに倒れる。
- 当たり: attack の位相 0.36〜0.48 の間に、相手が中心間 175cm 以内かつ正面 ±34° 以内。
- リング: 半径 500cm。外には出られない(場外負けなし)。
- CPU: 遠ければダッシュで寄る→間合いの外は歩いて寄る/横へ回る→間合いに入ると斬る(連続して斬らない待ち 0.6〜1.5秒)。プレイヤーが振りかぶると、ときどき下がる。
- 見分け: CPU は着物の色相を回して臙脂にする。
- カメラ: プレイヤーの右肩後ろから相手の方を見る。
- ステップ: 待機・すり足(どちらも構えたまま)の最中に Shift を押した瞬間、入力している方向へ 160cm を 0.28秒で動く(出だしが速く止まり際がゆっくり)。向きは相手のまま。方向キーを押していないと出ない。ステップ中は斬れない。無敵時間はなく、間合いや正面の角度から外れることで避ける。専用モーションはなく、構えの姿勢のまま滑る。Shift を押したままならステップのあとダッシュになる。CPU はステップしない。
- 確認用クエリ: `?sim=秒` でその時間ぶん進めてから描く、`&auto=1` でプレイヤーも自動で前進して斬る。`&step=1` で CPU が振りかぶるとプレイヤーが右へステップする。
