# POP 参考画像

書店POPの参考として集めた画像。「なぜ良いか」を一言メモ(目視で読み取った事実のみ)。

| ファイル | 特徴 |
|---|---|
| 01_手書き6枚コラージュ_吹き出し付き | 背景は付箋色(黄・橙・ピンク・水色)。見出しだけ極太の黒、本文は小さく細い。吹き出し(白)で「一言」を別枠に出す。装飾枠はマスキングテープ風 |
| 02_本屋大賞_似顔絵と3枚 | 似顔絵+黄色い本型の台紙。受賞歴は小さい吹き出し。下2枚は和柄/楽譜の薄い背景+表紙写真を貼る |
| 03_漫画家直筆_白黒カード | 白黒のみ(トーン含む)。見出し文字が2種(ゴシック・中抜き)。絵が主役で文字は余白に配置 |
| 04_店頭_オレンジ地_矢印 | 単色(オレンジ)地+黒文字。矢印で「→ 次の本」へ誘導。ピンクの塗りで強調語だけ目立たせる |

## 共通して見えること
- 見出しは本文の3倍前後の大きさ。一番言いたい一言だけが大きい
- 背景色は1色が基本。装飾は薄い模様か枠のみ
- 吹き出し・矢印など、視線の入口と出口が決まっている
- 情報(価格・著者)は最下部の小さい文字にまとめる
