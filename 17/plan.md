# day17 ネズミになってリビングと壁裏を走るゲーム

起動: `17/index.html` をブラウザで開く(クリックで開始)。
モデル単体の確認: `preview.html?m=<ファイル>&f=<関数>`、撮影は `./shot.sh`、ゲーム画面の撮影は `./shot_game.sh`。

## ユーザーが決めたこと
- ネズミになってリビングや壁裏を走り回る。3D。
- 見た目にこだわる。モデルはサブエージェントで作る。方式は Three.js のコードで組む(A案)。
- 家具の中身はアイデアの内部なので Claude が決めてよい。床や壁も詳細に。
- 人間視点でもプレイしたい(H キーで切り替え)。

## Claudeが仮決めしたこと(差し替え可)
- 部屋 600×500cm、天井 240cm。奥と左の壁が中空で、穴は奥の壁 x=150 と左の壁 z=120。
- 家具: ダイニングテーブル+椅子4脚、ソファ、ローテーブル、ラグ、テレビ台+テレビ、本棚、フロアランプ、観葉植物。配置は `index.html` の LAYOUT。
- 操作: WASD/矢印で移動、Shift でダッシュ、Space でジャンプ(約30cm)、マウスで視点、ホイールで距離。
- 速さ 85cm/秒(ダッシュ 170)。2.5cm までの段差は自動で乗り越える。
- 壁の中に入ると部屋の明かりが弱まり、穴から差す光だけが目立つ。
- 人間視点: 一人称、視点の高さ 133cm、肩幅 40cm・身長 160cm の当たり判定、20cm までの段差はまたぐ。歩き 140cm/秒、小走り 320cm/秒、ジャンプ約35cm。ドア前(x=220, z=190)から始まる。
- 人間視点の間、ネズミはその場に止まって待つ。切り替えた位置と視点はそれぞれ覚えている。
- ゴール・敵・得点などの遊びの中身はまだ無い(ユーザーが決める)。

## モデルの担当ファイル
| ファイル | 中身 |
|---|---|
| models/mouse.js | ネズミ(脚・尻尾・耳・ひげを動かせる) |
| models/room.js | 床・壁・天井・窓・ドア・ネズミ穴 |
| models/wallInside.js | 壁の中(土台・欠き込み付きの柱・断熱材・配線・配管・ほこり) |
| models/dining.js | ダイニングテーブル・椅子 |
| models/lounge.js | ソファ・ローテーブル・ラグ |
| models/storage.js | テレビ台・本棚・フロアランプ・観葉植物 |
