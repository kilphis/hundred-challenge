# モデル共通仕様(day17 ネズミのゲーム)

## 技術
- Three.js r128(グローバル `THREE`。`<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js">`)。ES module は使わない(file:// で開くため)。
- 1ファイル = 担当モデル群。ファイルは自己完結。他のモデルファイルを読まない・書かない。
- 登録の形:
  ```js
  window.MODELS = window.MODELS || {};
  window.MODELS.diningTable = function () { const g = new THREE.Group(); ...; return g; };
  ```
- 外部画像は使わない。木目・布・壁紙などの質感は CanvasTexture で手続き的に描く(繰り返し、色ムラ、継ぎ目、汚れ)。
- マテリアルは MeshStandardMaterial / MeshPhysicalMaterial。ライトはモデルに入れない(ゲーム側が用意する)。光る部分は emissive で表現。
- 全メッシュに `castShadow = true; receiveShadow = true`(薄い布などで不要なら false 可)。
- 性能: 1モデルあたりドローコール目安 150 以下。同じ形が大量に並ぶなら InstancedMesh か mergeBufferGeometries 相当を自作。テクスチャは 1024px 以下。

## 座標と単位
- **1 = 1cm**。Y 上向き。
- 家具: 原点 = 床に接する足元の中心(底面 y=0)。正面は +Z を向く。
- room / wallInside: ワールド座標そのまま(原点に置かれる)。

## 当たり判定(必須)
- `group.userData.colliders = [[minX,minY,minZ,maxX,maxY,maxZ], ...]` をグループのローカル座標で付ける。
- 軸に沿った箱(AABB)だけ。プレイヤー(ネズミ、幅約5cm・高さ約6cm)が「ぶつかる/上に乗る」形の近似。
- 細部は要らないが、ネズミが通れる隙間・乗れる面は箱でちゃんと表す(椅子の座面、テーブル天板、脚、棚板など)。
- 床や地面より下は不要。

## プレビューと撮影
- `preview.html?m=<ファイル名>&f=<関数名>` でブラウザ表示(ドラッグで回転)。`&col=1` で当たり判定を赤い線で表示。
- 撮影: `./shot.sh <ファイル名> <関数名>` → `shots/<関数名>_{persp,front,side,top,close}.png`
- 任意カメラ: `./shot.sh <ファイル名> <関数名> <名前> "cam=x,y,z&look=x,y,z"` → `shots/<関数名>_<名前>.png`
- **ネズミ目線で見られるゲーム**なので、低い位置・近距離からの見た目(脚の付け根、裏側、床の継ぎ目)が大事。close/任意カメラで低い視点も必ず確認する。

## 部屋レイアウト(全員共通の前提)
- 部屋の内側: x ∈ [-300, 300], z ∈ [-250, 250], 床 y=0, 天井 y=240。
- 奥の壁(z=-250 側)と左の壁(x=-300 側)は**中空の壁**。ネズミが中を走れる。
  - 奥の壁: 室内側の石膏ボード z ∈ [-251.2, -250] / 空洞 z ∈ [-260.2, -251.2](深さ9cm) / 外側の石膏ボード z ∈ [-261.4, -260.2]。x ∈ [-311.4, 300]。
  - 左の壁: 室内側ボード x ∈ [-301.2, -300] / 空洞 x ∈ [-310.2, -301.2] / 外側ボード x ∈ [-311.4, -310.2]。z ∈ [-261.4, 250]。
  - 2つの空洞は角(x≈-305, z≈-255)でつながっている。空洞の端(x=300 側、z=250 側)は閉じている。
  - 空洞の床 = y=0(土台の角材の上面が y=0)。
  - **ネズミ穴**(室内→空洞): 奥の壁 x=150 中心、左の壁 z=120 中心。幅 9cm・高さ 8cm(上がアーチ形)、下端 y=0。
- 右の壁(x=300)と手前の壁(z=250)は普通の壁(厚さ12cm、中は詰まっている扱い)。
- 窓: 右の壁 z ∈ [-120, 40], y ∈ [80, 210]。ドア: 手前の壁 x ∈ [180, 265], y ∈ [0, 205]。
- 担当: 室内側/外側の石膏ボード・壁紙・巾木・床・天井・窓・ドア = room.js。空洞の中身(柱・土台・断熱材・配線など) = wallInside.js。

## 描画設定(ゲーム本体も同じ)
- 出力はリニアのまま(outputEncoding・toneMapping は既定)。**色の16進指定は見たままの色で出る**。CanvasTexture もエンコーディング指定不要。
- ライト: HemisphereLight(0xfff6e8, 0x4a4038, 0.5) + 影付き DirectionalLight(0xfff1dc, 0.8) + 補助 PointLight 0.3。この明るさで見え方を確認する。
