# day40 学びメモ — 「おしゃれ」は何でできていたか

仮説: html でおしゃれにならなかったのは、CSS とデザインライブラリを使わなかったから。
結果: 使ったら、素のままの前回までとは別物の見た目になった。何がどこで効いたかを分けて残す。

## 見た目を作った道具(どこで何をしたか)
| 道具 | 効いた所 | 場所 |
|---|---|---|
| CSS 変数 `--h`(色相1つ) | 背景のグラデ3枚・文字の光・ボタンの色が、1つの値から連動して変わる | `style.css` の `.stage` |
| `radial-gradient` を重ねる | 単色の背景が「光が滲む空間」になる | `.stage .bg` |
| SVG `feTurbulence` | フィルムのような粒子。画像ファイル無しで質感が出る | `.bg::after` |
| `backdrop-filter: blur` + 薄い白の border/内側ハイライト | ガラスのパネル(めくった裏面・ボタン) | `.pill` `.back` |
| `text-shadow` を色相から作る | 単語がうっすら発光する | `.word` |
| `container-type: size` + `cqw` | 小さな枠(gallery)でも大きな枠でも、文字と配置が同じ比率になる | `.stage` `.word` |
| GSAP | 文字を1字ずつ(stagger)動かす、図形を時間で並べる(timeline)、`--h` を滑らかに変える | `fx_*.js` |
| tsParticles | 紙吹雪・金貨・漂う粒・線でつながる点(物理的な粒の群れ) | `fx_core.js` |

## 踏んだ罠(次に同じ道具を使うとき)
1. tsParticles は `loadFull(tsParticles)` を先に呼ばないと **エラーも出さず何も描かない**。
2. 粒の色は `hsl(210 90% 60% / 1)`(空白区切り)を読めない。`hsl(210, 90%, 60%)` で渡す。CSS では空白区切りでよい。
3. 不透明度のアニメで「最小=最大(value:1)」だと、生まれた瞬間に最小に達して消える。幅(min:0,max:1)を持たせる。
4. GSAP は遅れが大きいと時間を縮める(lagSmoothing)。撮影(仮想時間)では `lagSmoothing(0)` が要る。
5. 動きの確認は「全単語の効果を同時に流す一覧」(`gallery.html`)を1枚撮るのが速かった。スクショ1枚で50個の死活が分かる。

## どう分けたか(読む順番)
- `defs.js` … 単語→効果の対応表。**ここだけ直せば見た目の割り当てが変わる**。`img` は「どんなイメージにしたか」の説明。
- `fx_core.js` … 舞台(Stage)・文字の動き・粒子の効果。`fx_shapes1/2.js` … 図形の効果(GSAP)。
- `app.js` … めくる・次へ・キー操作だけ。
