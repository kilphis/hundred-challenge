# day18 雲の巨人(PixiJS)

起動: `18_cloud_giant/index.html` をブラウザで開く。1〜4キー or 下のボタンで状態を切り替える。`?s=3` で最初の状態を指定(撮影用)。

## ユーザーが決めたこと
- 2Dを PixiJS で作る。
- 雲の巨人。感情に合わせて膨らむ・雨雲になる・ストームを起こす。
- 体に影をつける。顔は渋く、ある程度作り込む(2026-11-12)。

## Claudeが仮決めしたこと(差し替え可)
- 状態は4つ: ふつう / 膨らむ / 雨雲 / ストーム。どの感情をどれに当てるかは未定なので、ボタン名は現象の名前にした。
- 巨人の体は約170個のぼかした円(雲粒)の集まり。部位は頭・胴・両腕・両手・下の雲の台。脚はなく、雲の台から上半身が生えている。
- 各状態の数値は `index.html` 冒頭の `STATES`:
  - 膨らむ: 大きさ1.3倍、雲粒が外へ広がる、腕を少し上げる、口が大きく笑う。
  - 雨雲: 灰色になり、空も曇る。腕と台から雨。眉が困り顔、口がへの字。
  - ストーム: 暗灰色、空は夜のように暗い。両腕を振り上げ、雨は横殴り、雲粒が激しくうねる。0.6〜2.8秒おきに雷(稲妻+画面フラッシュ)。眉が怒り顔。
- 影: 雲粒1つずつに「影色の本体+左上にずらした光」を重ねる(光は左上から)。体は上ほど明るく下ほど青灰色。頭が胸に、胴が雲の台に影を落とし、地面にも巨人の影が落ちる。
- 顔(渋い老人): 額の横じわ3本、眉間の縦じわ、太く毛羽立った雲の眉、目のくぼみの影、切れ長で上まぶたの重い目、目の下のたるみと目尻のしわ、雲の鼻、ほうれい線、頬骨の下の影、口ひげ、胸まで垂れるあごひげ(揺れる)。眉・ひげは顔より白く塗る。
- 表情: ふつう=眉を少し寄せ口は一文字、膨らむ=目を細めて口角が上がる、雨雲=眉尻が下がり額のしわが深く口はへの字、ストーム=眉を吊り上げ目を見開き口を開ける。
- 状態はゆっくり(約1秒)移り変わる。常に呼吸のように2%伸び縮みし、左右に揺れ、まばたきする。
- 背景は空のグラデーションと緑の丘。暗くなると丘も暗くなる。
- Live2D / Spine / VTuber(顔の動きで動かす)は未着手。
