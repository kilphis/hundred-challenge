# day18 雲の巨人(PixiJS)

起動: `18_cloud_giant/index.html` をブラウザで開く。顔追跡を使うときは `./serve.sh`(ローカルサーバーで開き、カメラを自動で起動)。
操作: 1〜5 長押しでその表情へ連続的に寄る(離すとそこで止まる)/ Q・W・E・R 長押しで天気(晴れ・曇り・雨・嵐)/ T 顔追跡 / H 表示を消す。`?wx=1〜4` で最初の天気。`?obs=1` で表示なし、`?cam=1` で顔追跡を自動開始、`?flip=1` で顔追跡の左右反転。`?s=3` で最初の状態を指定。撮影は `./shot.sh [番号...]` → `shots/s<N>.png`。`?mx=..&my=..` でカーソル位置を固定(撮影用)。

## ユーザーが決めたこと
- 2Dを PixiJS で作る。
- 雲の巨人。感情に合わせて膨らむ・雨雲になる・ストームを起こす。
- 体に影をつける。顔は渋く、ある程度作り込む(2026-11-12)。
- 2026-11-13: ユーザーのラフ「いかついが、どこかふとした時に優しそうなおじさん」で作り直し。
  ラフの要素: 強面・太い眉・丸く大きい目(愛嬌)・口髭と顎髭・しっかりした首・傷跡(あっても目は優しい)・坊主頭・耳・腕組み・
  表情は「普段: いかつい」「豪快な笑顔(目尻が下がる)」「ふとした時: 優しい」。

## Claudeが仮決めしたこと(差し替え可)
- 状態は5つ: ふつう / 膨らむ / 雨雲 / ストーム / ふとした時。どの感情をどれに当てるかは未定なので、ボタン名は現象の名前にした。
- 巨人の体は約170個のぼかした円(雲粒)の集まり。部位は頭・胴・両腕・両手・下の雲の台。脚はなく、雲の台から上半身が生えている。
- 各状態の数値は `index.html` 冒頭の `STATES`:
  - 膨らむ: 大きさ1.3倍、雲粒が外へ広がる、腕を少し上げる、口が大きく笑う。
  - 雨雲: 灰色になり、空も曇る。腕と台から雨。眉が困り顔、口がへの字。
  - ストーム: 暗灰色、空は夜のように暗い。両腕を振り上げ、雨は横殴り、雲粒が激しくうねる。0.6〜2.8秒おきに雷(稲妻+画面フラッシュ)。眉が怒り顔。
- 影: 雲粒1つずつに「影色の本体+左上にずらした光」を重ねる(光は左上から)。体は上ほど明るく下ほど青灰色。頭が胸に、胴が雲の台に影を落とし、地面にも巨人の影が落ちる。
- (11-12版の渋い老人の顔・長いひげは、11-13のラフで置き換えた)
- 体: 太い首、僧帽筋、大きな肩、胸板、腹。腕は肩→肘→拳の2節で、上腕にふくらみ。
- 頭: 角ばった輪郭で下(あご)が広い。坊主頭は顔より少し濃い雲。耳あり。
- 顔の線: 太い眉(内側が太く外へ細る、毛の線つき)、丸い黒目に白い光2つ、眉間の縦じわ、太い鼻と小鼻、ほうれい線、無精ひげ(短い線で口ひげ・顎髭・あごの線)。
- 傷跡: 本人から見て左(画面右)。額から眉へ1本、目の下から頬へ1本。縫い跡の短い線つき。
- ラフの表情を状態に割り当てた:
  - ふつう=「普段: いかつい」。眉を寄せて下げ、口はへの字、腕組み。目は丸いまま。
  - 膨らむ=「豪快な笑顔」。目をつぶって目尻を下げ、歯を見せて大きく笑う。腕を広げる。頬が少し赤い。
  - ふとした時(新しく足した5番)=「ふとした時: 優しい」。眉尻を下げ、穏やかに微笑み、頬が赤い。
  - 雨雲=困り眉+への字、腕を垂らす。ストーム=眉を吊り上げて叫ぶ、腕を振り上げる(この2つはラフに無いので前のまま流用)。
- ラフの帽子・Tシャツ・汗の線は入れていない。
- 状態はゆっくり(約1秒)移り変わる。常に呼吸のように2%伸び縮みし、左右に揺れ、まばたきする。
- 背景は空のグラデーションと緑の丘。暗くなると丘も暗くなる。
- Live2D / Spine / VTuber(顔の動きで動かす)は未着手。

- 2026-11-13: ピンク基調(ユーザー指示「色はピンク、毛もピンク、目も濃いピンク」)。体は淡いピンク〜下ほど濃いピンク、影は赤紫。坊主頭・眉・無精ひげは顔より濃いピンク。黒目とまぶたの線は濃いピンク(#c2185b)。雨雲・ストームではくすんだ紫がかったピンクに暗くなる。口・しわの線も黒から濃い赤紫系に変えた。空・地面・雨の色はそのまま。
- 2026-11-13「雲で彫る」(ユーザー選択): 顔の線をやめ、雲粒の盛り上がりと影で作り直した。
  - 盛り上がり(粒): 眉骨・上下のまぶた・頬骨・鼻筋と丸い鼻先・小鼻・あご・下唇。上まぶたの粒が下りると黒目が隠れる(まばたき・笑い目)。
  - 影: 目のくぼみ(眉と一緒に動く)・眉間・困った額・頬骨の下・ほうれい線・鼻の下。
  - 毛(ピンクの粒): 眉(内側が太い)・口髭(両端が垂れる)・あご髭・あごの無精ひげ(薄いピンクの影)。
  - 口: 閉じた口は影の点を曲線に並べる。笑う・叫ぶは暗い穴+雲の歯。
  - 線で残したもの: 黒目と光、傷跡(雲に刻んだ溝として影色+光の2本)、笑い目の弧、目尻のしわ、耳の内側。
  - 体: 粒の大きさをばらつかせ、胴の輪郭と腕のまわりに小粒を足した(数珠つなぎ対策)。
- 2026-11-13 表情キー(ユーザー指示「ボタンにせず連続的に」): ボタンを廃止。数字キーを押している間、その状態の割合が増えていく(約2秒でほぼ100%)。離すとその混ざり具合で止まる。複数の状態が混ざる(例: 膨らむ56%+ストーム29%で、笑いながら小雨)。混ざり具合は左上に表示。
- 2026-11-13 顔追跡(ユーザー指示): MediaPipe の顔ランドマーク(ブラウザ内で処理)。鏡のように動く。
  - 自分の顔から取るもの: 左右別のまばたき、口の開き(叫ぶ口)、口角、眉(下げる/内側を上げる)、視線(カーソルより優先)、頭の傾き・首振り・うなずき。
  - 頭の傾きは頭全体を回す。首振り・うなずきは顔の部品を頭より大きくずらして立体に見せる。うなずきの正面は追跡開始から約1秒の平均。
  - 体・天気・笑い目・頬の赤み・歯を見せる笑いは表情キーのまま(顔追跡では変えない)。
  - 確認: 公開テスト写真を傾けた偽カメラ映像で「追跡中」になり、頭の傾き・口角が動くのを確認。実際のカメラでの左右の向き・感度は未確認(逆なら `?flip=1`)。ユーザーのラフ(線画)は顔として検出されなかった。
- 2026-11-13 口(ユーザー指示「開くと出る白が気になる」「もっと過剰に大きく開けて」): 口を開けたときの歯(白い粒)をなくした(歯は「豪快な笑顔」のときだけ)。開いた口は縁のくっきりした暗い穴にし、最大で幅約84・高さ約84(顔の座標)。下唇・あご・あご髭・頭の輪郭の下側が最大56下がる。顔追跡では少し口を開けただけで大きく開く(jawOpen 0.03〜0.28 で全開)。
- 2026-11-13 天気(ユーザー指示「天気を変えられるようにして」): 表情とは別に Q/W/E/R の長押しで、晴れ・曇り・雨・嵐へ連続的に寄る(表情キーと同じ仕組み・同じ速さ)。
  - 天気の中身: 曇り=雲と空が灰色に暗くなる / 雨=さらに暗く雨 / 嵐=夜のような空・横殴りの雨・雷。種類は今ある要素(暗さ・雨・風と雷・空の色)だけで作った。
  - 表情の「雨雲」「ストーム」が持つ天気は残した(感情で天気が変わるのが元の発想のため)。表情と天気が重なったら、暗さ・雨・嵐は強いほうを使う。空の色は晴れ以外の割合だけ天気の空へ寄せる。
  - 例: 「膨らむ」(豪快な笑顔)+嵐 → 笑いながら嵐。晴れにしても「ストーム」の表情ならストームのまま。
