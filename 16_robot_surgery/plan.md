## 4. Claude が決めた内容(2026-11-12。差し替え可)

- 施術(ボスの指示)3つを順に。どれも血管(赤い線)に先端が触れたら失敗、時間切れも失敗。
  1. 切開(30秒): 点線を始点→終点へ、左クリックを押したままなぞる。線から9px外れたら失敗。
  2. 摘出(30秒): 患部(紫の丸)をつかんで回収袋へ運ぶ。間に血管があるので迂回が要る。
  3. 縫合(40秒): 切開線の両側の刺入点8つを番号順にクリック。半径8px外したら失敗。
- 視点は 2D 俯瞰。器具は1本(両手・クラッチ・カメラ操作は未選択なので入れていない)。
- 感度 = 実機の動きの縮小倍率 1.5:1 / 2:1 / 3:1 を 1/2/3 キーで切替。マウスの動き ÷ 倍率 が器具の動き。
- 失敗したら R でその施術だけやり直し。全部終わると合計時間を表示。
