# GPU 版の計測結果

- 日時: 2026-11-17 13:47
- GPU: Apple M4(10コア GPU、Metal)
- 画面(動ける範囲): 920×780 px、マス幅 50 px(CPU 版の計測と同じ)
- 「計算」= GPU のタイムスタンプで測った、計算パスの始めから終わりまで(転送・起動の手間を含まない)
- 「待ち込み」= CPU から見て、命令を積んで送ってから終わるのを待つまで(1ステップずつ送って待つ)
