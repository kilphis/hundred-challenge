何を見ているか

点群の各点を中心に半径 ε/2 の球を膨らませる。2点の距離が ε 以下なら辺を張り、3点が互いに ε 以下なら三角形で埋める(四面体以上も同じ規則で入るが表示は三角形まで)。これがヴィートリス・リップス複体 VR(ε)。

ε を 0 から大きくすると、ばらばらの点(β₀ = 点の数)がつながって成分が減り、辺が輪を作ると β₁ が増え、輪の内側が三角形で埋まると β₁ が減る。各輪が「生まれた ε」と「埋まった ε」の組がバー。長いバーほどデータの形として確か、短いバーはノイズ。

計算は係数 Z/2 の境界行列の列簡約(このページ内の JavaScript)。計算は包含半径(どれか1点から全点が ε 以内になる値。これを超えると複体は錐になり輪はすべて消える)まで行い、スライダーは最後のバーが終わる少し先までを映す。4つのデータで ripser と全バー一致を確認済み(tools/check.js)。

オレンジの輪: 「輪を最短で表示」がオンのときは、その輪を生んだ辺と、その直前の複体での最短路をつないだ輪(見やすさ優先の近似。厳密にはこの輪がバーの死と同時に消えるとは限らない)。オフにすると簡約した境界行列の列そのもの(誕生時に存在し、死の時刻に三角形の境界の和として埋まる正確な代表。Z/2 の和なので輪が重なって見えることがある)。

座標は各データを [-1,1] に収めて計算し、ε は元の単位にも換算して表示。自前の点群は CSV をこの画面にドロップ(200点を超えたら最遠点サンプリングで200点に)。
