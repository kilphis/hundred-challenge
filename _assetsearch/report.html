道具ごとの所見

API 直叩き（search.py）

Poly Haven / ambientCG / Openverse・キー不要
  • 音は license=cc0 で絞れ、長さ（秒）も返る。効果音か BGM かは長さでだいたい分かる。
  • 実装は 100 行弱。MCP を入れずに uv run search.py "coin" --kind audio で Claude がそのまま使える。
  • 弱点：3D は Poly Haven（重い写真スキャン）だけ。ローポリは入っていない。

threenative-asset-mcp

ThreeNativeHQ・npm・ライセンス表記 UNLICENSED
  • ライセンスの扱いが一番丁寧。ダウンロード時に acceptLicense: true を必須にし、クレジット文まで返す。
  • Polyfork のローポリは三角形数・リグの有無つきで、ゲームにすぐ使える。
  • 音声カタログは7パックだけで、「coin」で0件。保存先が初期設定だと ~/Downloads になる。
  • Fab 用のコードは、ブラウザになりすましてボット対策をくぐる作り。この部分は使わなかった。

3d-asset-server

arielshad・★341・Apache-2.0
  • 検索の網は最も広い（BlenderKit / Polyfork / Quaternius / Sketchfab / itch…）。サムネイル・無料かどうか・ポリゴン数も返る。
  • 有料の itch 商品が上位に混ざる。BGM なのに type が texture のものがある。
  • Kenney の「ダウンロード成功」は、実際にはトップページの HTML（10KB）だった。成功の返事を信用できない。
  • 利用統計の送信が初期設定でオン。ASSET_SERVER_TELEMETRY=0 で止めて動かした。

ASSETMCP

evonar543・★6
  • そのままでは起動しない（依存の指定 mcp>=1.28 で v2 が入り、API 変更で落ちる）。mcp<2 に固定して動いた。
  • ダウンロードすると ASSET_MANIFEST.json と CREDITS.md が自動でできる。この発想は真似したい。
  • Kenney の巡回は0件・ダウンロード失敗（サイト構造の変化）。OpenGameArt はライセンスを読み取れず、全部「不明なので禁止」になる。
  • itch は毎回同じ作者名を返すだけで、壊れている。

game-asset-mcp

jbcom
  • 手元の GLB に目録（面数・アニメ数・サイズ）を作って検索する道具。外の素材を探す道具ではない。
  • 環境変数名が設定側と DB 側で食い違っていて、そのままでは DB を開けない。CLI の ingest も依存ライブラリの API 変更で落ちる。
  • 回避すると動く。数えるのは .glb だけで、検索はファイル名の一致。

LoopLoop 索引 API

api.looploop.dev・キー不要
  • パック単位。各パックに画風タグ（例：soft-edges, chunky-style, toy-like-aesthetic）がついていて、統一感で選べる。
  • downloadType が agent / manual / donate / paid に分かれ、エージェントが取ってよいかが分かる。
  • 音は少ない（「coin」2件、「dungeon」2件）。

arcane-assets-mcp

npm のみ・リポジトリ無し
  • Kenney の24パックをコードに直接書き込んだ一覧。「tree」で0件。
  • ダウンロード URL も固定で、古くなっている可能性が高い。Kenney の意思表示に合わせて試さなかった。

game-artist スキル

ikatechis/claude-agentic-mastery
  • 「Kenney 全部入り（3.6 万点）を手元に置き、Preview.png やスプライトシートを Claude が画像として見て選ぶ」という手順書。
  • 作者のゲームのパスや画風に固定されていて、そのままは使えない。考え方は Kenney の扱いの正解に近い。

安全面で気づいたこと

  • 個人が作った MCP 6つのうち、そのまま動いたのは2つ（threenative / arcane）。残りは依存のずれ・設定の不整合・初期設定の問題を手で直す必要があった。
  • 利用統計の送信（3d-asset-server）、ボット対策回避のコード（threenative の Fab 部分）、勝手な保存先（threenative の ~/Downloads）は、コードを読むか動かすまで分からなかった。
  • 「成功」と返して中身が HTML（3d-asset-server の Kenney）という事故があった。落としたファイルの種類を file コマンドなどで確かめる一手が要る。
  • Kenney は CC0 だが、サイトは AI による収集を望まない（robots: noai, tdm-reservation: 1）。素材の利用はよくても、エージェントにサイトを巡回させるのは別の話。

おすすめの組み合わせ

  1. 音：search.py --kind audio（Openverse → Freesound CC0）。原音が欲しくなったら Freesound の API キーを足す。
  2. ゲーム向け 3D：threenative の Polyfork 系ツールだけを使う。CC BY のクレジット文はそのまま記録する。
  3. テクスチャ・HDRI：search.py（ambientCG / Poly Haven）。
  4. 画風をそろえたいとき：LoopLoop で画風タグからパックを選ぶ。
  5. Kenney：自分で落としたパックを手元のフォルダに置く。Claude は Preview.png を画像として見て選ぶ（game-artist の考え方）。
  6. 記録：ASSETMCP 流に、取ったものは manifest と CREDITS に自動で残す。

生の結果は results/、試験用スクリプトは mcp_call.py（MCP を1回呼ぶ）と search.py（API 直叩き）。他人のリポジトリは作業用の一時フォルダに clone して動かした（vault には入れていない）。
